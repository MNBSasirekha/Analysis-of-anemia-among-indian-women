# Results

This folder contains the outputs generated from the analysis.

## Figures

The `figures/` directory contains charts and graphs generated during the project.

## Tables

The `tables/` directory contains important analytical tables and summaries.

The project generates results related to:

- State-wise anemia prevalence
- District-wise anemia prevalence
- Risk Score
- Risk Category
- Correlation analysis
- Machine learning model performance
