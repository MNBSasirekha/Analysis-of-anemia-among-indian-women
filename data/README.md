# Dataset

This folder contains the dataset used for the Data Analysis project.

## Dataset

The project uses district-level NFHS-5 data for India.

## Source

Official dataset source:

https://www.kaggle.com/datasets/kmldas/india-national-family-health-survey-nfhs

## Dataset Usage

The dataset is used for:

- Data preprocessing
- Data validation
- Data extraction
- Statistical analysis
- Data visualization
- Machine learning

## Dataset Privacy

The project uses publicly available aggregated/district-level data and does not contain private API keys, passwords, or confidential credentials.
